# Security policy

We take security reports seriously.

## Reporting a vulnerability

**Do not report exploitable vulnerabilities in public GitHub issues.**

For a vulnerability affecting a Mosaify repository, navigate to that repository's **Security** tab and use **Report a vulnerability** if private vulnerability reporting is enabled.

If that option is unavailable, contact the repository maintainers through an established private channel. Do not publish sensitive exploit details while seeking a secure reporting route.

Include a clear description, affected component and version or commit, impact, and minimal reproduction steps when safe to share.

We have not published a universal response-time SLA or a list of supported versions. Check each repository for any more specific security policy.
