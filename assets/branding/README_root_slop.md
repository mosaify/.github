# Mosaify organization community files

This repository provides the organization profile and shared community templates.

- `profile/README.md` — public organization overview
- `profile/assets/` — logo and banner
- `ISSUE_TEMPLATE/` — issue forms
- `PULL_REQUEST_TEMPLATE.md` — shared pull request checklist
- `CONTRIBUTING.md` — contribution guidance
- `SECURITY.md` — vulnerability reporting guidance

Create a **public repository named `.github`** under the Mosaify organization and commit these files at the repository root.

To set the **organization avatar**, upload `profile/assets/mosaify-avatar.png` manually in GitHub organization settings. GitHub does not derive the avatar from this repository.
